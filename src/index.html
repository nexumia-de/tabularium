Git Sync

Super Productivity syncs into a local folder; Git Sync keeps that folder in a private GitHub repository and takes the changes Day Planner sends.

Set Up Step by Step
  1. Create a private repository for the sync folder on GitHub (the form opens filled in).
    Create Repository
  2. Create a token for this computer. Name, expiry and “Contents: read and write” are filled in; under “Repository access” choose “Only select repositories” and pick the new repository.
    Create Token

  4. Created if missing. An empty folder takes what the repository holds; an empty repository takes what the folder holds.

  5. In Super Productivity: Settings → Sync → Local file, choose that folder and switch on manual sync only. Git Sync then syncs every few minutes; Sync Now below starts one at once.
