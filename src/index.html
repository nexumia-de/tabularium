Git Sync

Super Productivity syncs into a local folder; Git Sync keeps that folder in a Git repository and takes the changes Day Planner sends.

Set Up Step by Step
  1. Create a private repository for the sync folder on GitHub (the form opens filled in).
    Create Repository
  2. Create a token for this computer. Name, expiry and “Contents: read and write” are filled in; under “Repository access” choose “Only select repositories” and pick the new repository.
    Create Token

  4. A new, empty folder; Git Sync copies the repository there.

  5. In Super Productivity: Settings → Sync → Local file, choose that folder and switch on manual sync only. Then Sync Now below.

The top folder of a clone of your private repository, on the branch main.

Full path; for Super Productivity as Flatpak: flatpak-spawn --host git
